# Chethan Rai - Full Stack Developer Portfolio

Welcome to my personal portfolio repository! This is a modern, responsive, dark-themed developer portfolio built with HTML5, Vanilla CSS3, Vanilla JavaScript, and FontAwesome icons.

## 🚀 Features

- **Hero Section**: High-impact branding, interactive CTA buttons, and custom glowing developer graphic.
- **About Me**: Overview of education (MCA), location, and technical interests.
- **Services**: Clean card grid highlighting Web Development, Web App Development, UI/UX Design, and Website Optimization.
- **Tech Stack**: Visual badges showcasing HTML, CSS, JavaScript, React, Node.js, MySQL, and Git/GitHub.
- **Featured Projects**: Portfolio project cards with live link actions and tech tags.
- **Why Choose Me & Process**: Detailed section breakdown outlining quality work, client focus, continuous learning, and development process steps.
- **Interactive Contact Form**: Integrated with **Web3Forms** for instant email delivery directly to inbox.
- **Responsive Layout**: Mobile-friendly hamburger navigation and smooth transitions across all device sizes.

## 🛠️ Built With

- **HTML5** - Semantic page markup
- **Vanilla CSS3** - Custom design system, CSS grid/flexbox, keyframe animations, glassmorphism
- **Vanilla JavaScript** - Intersection Observers, mobile navigation toggle, modal controls, and async fetch API
- **Web3Forms** - Serverless form handler
